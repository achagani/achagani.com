# achagani.com

Personal site for Aslam Chagani — light editorial static site, no build step.

- `index.html` — hero, career timeline, project grid, notes placeholder
- `projects/*.html` — deep dives (problem, approach, trade-offs, stack)
- `assets/style.css` — shared design (Source Serif 4 + Inter, warm paper, copper accent)
- `CNAME` — achagani.com (GitHub Pages convention; harmless on other static hosts)

Pure static HTML/CSS — deployable to GitHub Pages, Cloudflare Pages, or the same host as
Folio once that hosting provider is finalized.
